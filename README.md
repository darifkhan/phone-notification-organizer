# Phone Notification Organizer

A DSA project in Python that organizes phone notifications.

## Data Structures Used
- **Heap (priority queue):** the most important notification is read first
- **Dictionary (hash map):** groups notifications by app
- **Stack:** undo the last read notification
- **Linear search:** search notifications by keyword

## Features
- Add, read and undo notifications
- View all by priority or grouped by app
- Search by keyword

## How to Run
1. Install Python 3
2. Run: `python main.py`
